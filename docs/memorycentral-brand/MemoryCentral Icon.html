MemoryCentral · Icon spec v3

The mark

Four corner brackets framing a single solid cell, with one diagonal connector from the top-left bracket to the cell. Two-tone: neutral gray brackets, cyan accent for the connector and the cell. Same SVG holds up on both light and dark surfaces.

Primary mark: Mark
Artboard: 24 × 24
Gray: #818487 · brackets
Cyan: #2ab1c0 · cell + connector
Light · warm paper / same file, no swap
Dark · cool ink / same file, no swap
01 — variants

Three signed-off forms. Primary handles everything; the pushed variant adds one cyber gesture for splash/launch; the wordmark lockup is for headers and documentation.

Mark Primary

Bracket frame in gray, cell + diagonal connector in cyan. The connector is the asymmetric move — a single line drawing the eye from the outer frame into the central memory point. Use everywhere by default.

Live Variant

Adds a dashed horizontal scanline through the artboard — a second cyber gesture stacked on the connector. Reserve for launch tile, splash, and the README hero. Not meant for favicon sizes.

Lockup Wordmark

Icon + dot-matrix LED panel. Two stacked lines: MEMORY in neutral gray, CENTRAL in the cyan accent that echoes the mark's center cell. Use for splash screens, README hero, and any moment that earns a brand statement.

02 — anatomy

Every measurement falls on a half-unit so the mark pixel-snaps cleanly at 16, 24, 32. The center cell is the only solid element; everything else is a 1.8-unit stroke.

Construction

Four L-shaped polylines at the corners (5-unit legs, 1.8 stroke, square linecaps) in #818487. One diagonal line from inside the top-left bracket to the cell's top-left corner, in #2ab1c0 at 1.5 stroke. One 5×5 filled cell at the center in the same cyan.

03 — size scale

Brackets get visually heavier as the mark shrinks — exactly what's needed for legibility at small sizes. No special small-size variant required.

App icon: 1024, 512, 256, 128
OS/Dock: 64, 48, 32
UI in-product: 24, 20
Favicon / tab: 16
04 — on color

Two-tone construction means the icon doesn't need to change file between light and dark contexts. Gray reads on either side; cyan stays vibrant against every neutral and saturates further against the brand surfaces.
